# 乐游 AI 报价核算工具

> **AI 帮你 30 秒出对客报价单** —— 旅行社定制游报价核算 + AI 自动填成本 / 完善行程 / 核价诊断。单文件 HTML，开箱即用。

一个面向**旅行社定制游 / 两日游报价场景**的前端核算工具。把成本、报价、人数敏感性、行程文案放在同一张表里实时核算，并内置「大模型参谋」：填自己的 API Key，让 AI 自动填成本、把行程补全写具体、做毛利体检。

**特性：零依赖单文件** —— 样式、脚本、logo 全部内联，下载 `index.html` 双击就能用，不上传任何数据到服务器；API Key 加密保存在用户自己浏览器里。

## AI 参谋（核心特性）

打开页面右下角「🤖 AI 助手」面板：

1. **🩺 连接测试** —— 一键验证 Key 与模型是否通（返回 HTTP 状态、耗时、示例响应）；
2. **💬 对话式改价** —— 用自然语言改表格：「把房费降到 200」「成团人数改到 40」；
3. **📝 自动填成本** —— 输入行程描述（目的地 + 人数 + 天数 + 标准），AI 按七大类生成整张成本表；
4. **🧹 完善行程** —— 第 1 天（您手写的目的地基准）锁死，自动把后面几天 + 费用含/不含 补全写具体（参考真实旅行社线路颗粒度）；
5. **🔍 智能核价诊断** —— 做毛利体检：倒挂、漏项、保本风险，输出健康分 + 问题清单 + 建议。

**安全**：
- API Key 用 **AES-GCM + PIN** 加密后存在浏览器 localStorage，刷新页面后输 PIN 解锁，**不离开本机**；
- 不填 PIN 则降级为轻编码存储（建议对外分发时提示用户填 PIN）；
- 公司名 / 定制师 / 电话 / 贴士等 PII **不会** 作为 prompt 发给模型；
- 模型推荐 `agnes-2.5-flash`（实测约 10 秒出结果，免费）；DeepSeek 官方地址浏览器 CORS 不通，需走 OpenRouter / ZenMux 中转。

## 使用方法（3 步）

1. 浏览器打开 `index.html`（或部署到任意静态托管）；
2. 右上工具栏 → 填公司抬头 / 出发日期 / 天数 / 成团人数 / 成人价 / 儿童价；
3. 中上「成本明细」区填实际数字（或点 AI 面板「📝 自动填成本」让 AI 出一版再改），下方「对客报价总览」自动刷新。

要对外报价：点「🖨️ 打印对客单 / PDF」，内部核算与 AI 面板自动不打印。

## 技术说明

- **单文件，无构建**：`index.html` 一个文件包含全部 HTML / CSS / JS，无 npm、无依赖，双击即用；
- **数据本地**：业务数据存 `localStorage.zhoubian_2day_cost_v1`，AI 配置存 `localStorage.zhoubian_ai_cfg_v1`（AES-GCM 加密）；
- **打印**：`@media print` 隐藏内部核算与 AI 面板，仅保留对客报价单；
- **AI 调用**：OpenAI 兼容 `/chat/completions`（SSE 流式 + 非流式双模式），任何兼容 OpenAI 接口的服务都能填；
- **HTTPS 前提**：AES-GCM 加密组件（Web Crypto）需 HTTPS 环境，本地文件（file://）或 HTTP 下会降级为轻编码。
